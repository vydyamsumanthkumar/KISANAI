# 🌾 KisanAI - AI Crop Disease Detector

I built this app for Indian farmers who lose their crops every season just because they couldn't identify a disease in time. KisanAI lets any farmer take a photo of their crop and get an instant AI diagnosis — in Telugu and English, no expertise needed.

---

## 💡 Why I Built This

Farmers lose crores every year due to undetected crop diseases. Most of them don't have access to an agronomist. KisanAI puts an expert in their pocket — just snap a photo and get the answer.

---

## 🚀 Features

- 📷 Upload a crop photo — AI tells you what's wrong instantly
- 🗣️ Full results in Telugu + English so every farmer understands
- 🌾 Works for Rice, Cotton, Chilli, Tomato, Maize, Sugarcane, Wheat, Groundnut, Soybean, Onion, Potato, Banana, Jowar
- 💊 Get Disease name, Cause, Treatment and Prevention — all in one place
- ⚡ Severity level shown clearly — Low, Medium or High
- 📱 Works great on mobile — because that's what farmers use

## ⚙️ How to Run Locally

### 1. Clone the repo
```bash
git clone https://github.com/vydyamsumanthkumar/KISANAI.git
cd KISANAI
```

### 2. Add your Gemini API Key

Create a `.env` file in the root:
```
REACT_APP_GEMINI_API_KEY=your_api_key_here
```

You can get a free key at [aistudio.google.com](https://aistudio.google.com/app/apikey)

### 3. Install and run
```bash
npm install
npm start
```

Open **http://localhost:3000** and you're good to go.
